# 🧠 Solo Agile Workflow Guide

This repo uses a solo-friendly Agile-lite structure to keep progress visible and development manageable.

## 🗂 Weekly Cycle
1. Review Project board (Backlog → Done)
2. Move 1–3 cards into “Next Up”
3. Work on one at a time
4. Optional: comment on progress or note blockers
5. End of week:
   - Move finished cards to ✅ Done
   - Note what went well / what's next

## 🧾 Story Template
As a [user], I want [feature] so that [value]

## 💡 Tips
- Keep scope small
- Use checklists inside issues
- Reprioritize weekly — flexibility > rigidity
